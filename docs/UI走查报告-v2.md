# 统一产品库 UI 走查报告 v2（v1.1.0 → v1.2.0）

**视角**：站在 4 类真实用户的角度（详见 `docs/用户任务走查.md`）逐屏走查 v1.1 截图（`screenshots/v1.1/`），按任务流重做后，再对 v1.2 截图和**打包后的 Electron 窗口**（`screenshots/E1~E3`，Xvfb 下运行 `release/linux-unpacked`，可见无边框窗口与自绘最小化 / 最大化 / 关闭按钮）做第二轮复查。

**分级**：P0 阻碍核心任务 / P1 明显影响效率或理解 / P2 细节打磨。**状态**：✅ 已修复 · 🟡 部分修复 · ⏳ 未修复（附原因）。

## 总体结论

v1.1 的视觉已经桌面化，但**信息架构是“功能清单”而不是“用户任务”**：
- 每天打开的人看不到“今天有什么新的”；
- 48 个来源抓取失败，界面里没有任何提示；
- 找竞品要先在列表里找到产品；
- 导出只能得到原始表格；
- 没有办法持续跟踪一个产品。

v1.2 围绕 5 个任务重组：
- 导航改为工作台 / 管理两层；
- 新增首页、我的关注、报告导出、首次引导；
- 详情字段按优先级分组，列表默认列精简；
- 设计系统文档化，并由单元测试强制执行；
- 安装包减小 37%~49%。

第二轮复查又发现并修复了 7 个问题（#27–#33），仍有 4 个 P2 未修复（见文末）。
