# 统一产品库 使用手册（v1.2）

## 1. 安装与启动

| 系统 | 文件 | 说明 |
|---|---|---|
| Windows 10/11 x64 | `ProductHub-Setup-1.2.0-win-x64.exe` | 一键安装到当前用户（无需管理员），完成后自动启动并创建桌面 / 开始菜单快捷方式 |
| Windows（免安装） | `ProductHub-1.2.0-win-x64-portable.exe` | 双击即用，适合 U 盘或没有安装权限的电脑 |
| Linux x64 | `ProductHub-1.2.0-linux-x86_64.AppImage` | `chmod +x` 后双击或在终端运行；也提供 `tar.gz` |
| macOS | 源码中 `npm run dist:mac` | 生成 dmg / zip（x64 + arm64） |

安装包未做代码签名。Windows 若弹出 SmartScreen，点「更多信息 → 仍要运行」。

**数据位置**：
- Windows：`%APPDATA%\统一产品库\data`
- Linux：`~/.config/统一产品库/data`

可通过菜单「文件 → 打开数据目录」找到。卸载不会删除数据。

## 2. 首次启动

1. 启动画面显示「正在准备数据…」：第一次启动会解压预置数据库和图片，约需几秒。
2. **欢迎引导**：
   - 第 1 步介绍主要功能；
   - 第 2 步确认数据已就绪（2,865 个产品、241 个来源）；
   - 第 3 步可以填写 OpenAI 兼容接口的 API Key，留空点「暂不配置」即可，所有功能都能离线使用；
   - 第 4 步完成后进入首页。
3. 中途有事可点「稍后继续」或按 Esc：下次启动会从这一步继续；点「跳过引导」则不再出现。
4. 想再看一遍引导：设置 → 帮助 → 重新显示新手引导。

## 4. 常用任务

### 4.0 找产品（v1.4）
- **一句话搜索**：在首页大搜索框（或产品库顶部，`Ctrl/⌘+F`）直接写需求，例如「帮团队做会议纪要的AI工具，支持中文」「类似 Notion 的开源笔记」「mac 上的截图工具」。支持中英文混写、拼音（doubao）和错别字（notoin）。
- **看懂结果**：
  - 列表上方的「理解为」显示系统把需求拆成了哪些词，以及扩展出的同义词。
  - 每行下方的「为什么匹配」说明命中原因：
    - ✓ 表示满足条件；
    - ? 表示无法确认（例如官网信息还没补齐）；
    - 「部分匹配」表示只命中了一部分词。
- **快捷条件**：「最近30天新上线 / 有免费版 / 开源 / 中文支持」是必须满足的条件。句子里提到的“免费”“开源”默认只作为加分项，点「偏好：…」可以改成必须满足。
- **联网搜索**：本地结果太少时，列表下方会自动出现「联网搜索」区。点「入库」把产品加入产品库，入库后会自动补齐官网信息；「全部入库」一次加入所有未在库的结果。某个来源失败时会显示黄色提示，不影响其他来源。
- **对比**：
  1. 勾选 2–5 个产品，点批量操作条的「对比」。
  2. 有差异的行用浅黄色高亮，可勾「只看差异」。
  3. 可导出 Excel 或 Markdown。
- **补齐信息**：在详情页「官网信息」卡片点「补齐信息」，或批量勾选后点「补齐信息」。卡片标题旁会显示信息是多久以前更新的。

### 4.1 每天看新增（首页）
打开应用默认进入「首页 · 今日新增」：
- **今日新增 / 近 7 天新增**：安装后从各来源新抓取到的产品。还没有同步过时，先显示预置数据里最近发布的产品。
- **我的关注**：关注的产品数量，以及有新动态（再次发布）的产品。
- **来源异常**：抓取失败的来源数量，点击直接进入已筛选好的列表。
- 右上角「立即同步」会立即抓取 5 个到期来源，完成后提示新增和失败数量。后台也会每分钟自动检查一次。

### 4.2 找竞品 / 相似产品
- 最快的方法：按 `Ctrl/⌘+K`，输入产品名，选「找『X』的竞品」。
- 也可以在产品详情点「找竞品 / 相似」，或在列表行右键选「查找相似产品」。
- 右侧 AI 面板会列出相似产品，可继续用自然语言提问，例如“有哪些开源的 AI 写作工具”。

### 4.3 查询产品（表单查询）
产品库顶部是普通表单：关键词、分类、标签、来源，按「查询」执行，「重置」清空。关键词边输入边搜索。
「更多条件」中还有：来源地区、商业模式、发布日期起止、最少票数、最少发布次数、收录方式、AI 总结、首次收录起、关注。
侧栏的分类、标签、来源、快捷视图点击后会自动填好表单。

### 4.4 关注产品
在详情右上角、列表行末尾或右键菜单点 ☆。在「我的关注」（`Ctrl+3`）中查看已关注的产品。关注的产品在任何来源再次发布时，首页「关注的产品有新动态」会显示它。

### 4.5 维护来源和规则
「来源与规则」（`Ctrl+4`）下有两个 Tab：
- **来源列表**：
  - 可按名称搜索、按状态筛选；
  - 每行可以设置抓取频率，可以立即抓取、编辑规则、停用；
  - 右键可查看该来源的产品、复制 GUID；
  - 「抓取日志」可查看最近 100 次运行记录。
- **抓取规则**：
  1. 输入列表页地址，点「AI 生成」；
  2. 检查生成的 JSON 规则；
  3. 点「测试」预览抓取结果；
  4. 保存到来源。
- 出现失败来源时，状态栏会显示红色的「N 个来源抓取失败 · 点击处理」。

### 4.6 导出报告和数据
- **分析与报告**（`Ctrl+5`）：「导出报告（HTML）」生成带 KPI、分类分布、热门产品 Top 20 的网页，可直接发给同事；也可导出 Markdown。
- **导出数据**：产品库工具栏的「导出」会按当前查询结果导出 CSV / Excel / JSON；「导入导出」页还支持导入产品、导入来源和重复产品合并。

### 4.6.1 批量操作（v1.3）
勾选行首复选框（或按 Space / Shift 连选 / Ctrl+A），列表上方会出现蓝色批量操作条，可以：关注、取消关注、加标签或移除标签、导出选中（CSV / XLSX / JSON）、删除。所有批量操作都能在 Toast 中「撤销」。

### 4.7 添加产品
点「添加产品」或按 `Ctrl+N`。官网与已有产品相同时，不会新建产品，而是合并为它的一个新版本。

## 5.1 撤销与出错时怎么办
- 删除、取消关注、批量操作后，底部 Toast 会显示「撤销」（6 秒内有效）。
- 网络或服务出错时，页面会显示「加载失败」和「重试」按钮；Toast 里也会提供「重试」。
- 表单填错时，字段下方会出现红色提示，点「保存」后光标会跳到第一个出错的字段。

## 6. AI 设置
设置 → AI：填写接口地址（OpenAI 兼容）、模型和 API Key，Key 只保存在本机。
- 未配置时为「AI 离线模式」：总结、分类、相似产品、规则推断都使用本地算法。
- 设置页的「批量 AI 总结」可一次处理 50 个还没有总结的产品。

## 7. 内部预览网站（只读）
在服务器上执行 `npm run build && npm run preview`，默认端口 8788。界面与桌面版一致，所有写操作都被隐藏，接口返回 403。

## 8. 常见问题
- **首页“今日新增”为 0？** 新增只统计安装后同步进来的产品。点「立即同步」或等后台自动同步即可。
- **有很多来源显示失败？** 部分网站会拦截自动访问（HTTP 403）或需要登录。可以在「抓取规则」里用 AI 生成规则后重试；确实无法抓取的来源可以停用。
- **图片显示为首字母？** 说明该产品没有抓到 Logo，或者处于离线状态，不影响使用。

## v1.5 内置全量历史数据

安装包内置 10.6 万个产品的离线数据（来自 176 个来源的历史存档）。首次启动时会解压并预热搜索索引（约 10 秒，期间界面可用但第一次搜索稍慢）。已安装旧版的用户可以用数据包更新，见 `docs/全量历史数据-v1.5.md`。

## 来源设置、代理与浏览器模式（1.9.1）
- 设置 → 网络与代理：代理默认「跟随系统」（Clash 开系统代理即可），也可手动填 HTTP / SOCKS5，点「测试连通」检查。
- 来源列表 → 每行「设置」：抓取方式（自动 / API / RSS / Sitemap / 静态页 / 浏览器网页 / 公开存档）、频率（可设为只手动）、条数页数、是否走代理、入口 URL、API Key、浏览器选择器。可以点「单源测试」先试抓。
- 「内置浏览器」：在里面登录或通过人机验证，Cookie 会保存，抓取时共用。
- 「只重试失败的源」、按失败原因筛选、勾选后批量启用 / 停用。
- 详见 docs/来源设置与抓取适配-1.9.1.md。
