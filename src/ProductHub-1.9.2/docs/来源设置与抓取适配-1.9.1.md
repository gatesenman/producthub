# 来源设置与抓取适配（v1.9.1）

## 一、用户电脑诊断（只读查询，未改动数据库）
- 636 个来源：577 正常、13 抓到 0 条、40 报错、6 已停用。
- 40 个报错：403 ×24（Toolify、TopAI、GetApp、SourceForge、Trustpilot、Gartner、SelectHub、SpotSaaS、Launching Next、Peerlist、极客公园、TechNode、YourStory、e27、EU-Startups、Saaspo、Startup Buffer 等），超时 ×8（GitHub Trending / 搜索、Microlaunch、Reddit、FeaturedCustomers），fetch failed ×6（Reddit ×4、Tools.so、FWOL），404 ×1（Insidr），412 ×1（IT桔子）。
- 系统代理：Clash Verge 已开（HKCU ProxyEnable=1，127.0.0.1:7897）；WinHTTP 直连、无代理环境变量。
- 结论：403 绝大多数是 Cloudflare / WAF 人机验证（响应头 cf-mitigated: challenge），与网络无关；超时和 fetch failed 是 1.9.0 用 Node fetch，不走系统代理导致。tools.so、fwol.cn 已失效。

## 二、新增设置
**设置 → 网络与代理（全局）**
- 代理：跟随系统 / 手动 HTTP·SOCKS5 / 不用代理，带「测试连通」按钮。
- 超时（默认 25 秒）、重试（2 次）、并发（4）、同站请求间隔（800 ms）、User-Agent。
- 桌面版的请求走 Chromium 网络栈，自动使用系统代理和 PAC（含 Clash）。抓取、存档、图片、AI 请求都走这里。

**来源列表 → 每个来源的「设置」**
- 启用 / 停用；频率（含「只手动」）；最多条数 / 页数；请求间隔；超时。
- 抓取方式：自动（官方 API → RSS → 静态页面 → 浏览器网页 → Sitemap → 公开存档，失败自动换下一个），或指定其中一种。
- 是否走代理：按全局 / 直连 / 走代理。
- 自定义入口 URL；API 地址、JSON 路径、API Key（密码框，只存在本机，不显示明文）、Key 放在哪个请求头；RSS、Sitemap 地址。
- 浏览器规则：入口页面（可用 {yyyy}/{m}/{d} 表示今天）、卡片选择器、字段选择器、等待元素、滚动次数、下一页按钮、自定义脚本。
- 会话：共享内置浏览器（登录一次各来源共用）或独立会话。
- 遇到人机验证时弹出可见窗口；失败时改走公开存档；只收带外部产品链接的条目。
- 状态：成功 / 失败次数、连续失败次数、最近方式、用时、条数、中文失败原因。
- 「单源测试」只试抓、不入库，会显示每种方式的尝试结果和样例。
- 来源列表新增：方式列、「状态 / 原因」列、按失败原因筛选、「只重试失败的源」、勾选后批量启用 / 停用 / 抓取、「内置浏览器」按钮。
- 这些设置保存在本机 source_settings 表，增量更新合并时不会被覆盖。

## 三、浏览器网页模式
- 用桌面版内置的 Electron 浏览器（默认隐藏窗口）真实打开网页，等待 JS 渲染，自动滚动、翻页，按选择器提取卡片。
- 持久会话 persist:ph-browser 会保存 Cookie。点「内置浏览器」可以自己登录或通过验证，之后抓取共用这个会话。独立会话为 persist:ph-src-*。
- 遇到人机验证页时先等 20 秒；如果来源开了「弹出窗口」，就显示窗口让你手动完成（最多 3 分钟），之后继续抓取；还不行就改走公开存档（Wayback）。
- **不做**：指纹伪造、反检测、修改 navigator / canvas / WebGL、stealth 插件、自动破解验证码。只有在你自己设了 UA 时才会改 UA。
- Product Hunt 内置规则：入口是首页和当日 All 榜 `leaderboard/daily/{yyyy}/{m}/{d}/all`（按美西日期）；卡片 `section[data-container]`，名称 `a[href^="/products/"]`，简介 `span.text-secondary`，票数取投票按钮。
- 其他内置规则：
  - HN 走 Algolia 官方 API；GitHub 搜索页走 Search API；Reddit 走 RSS，间隔 3 秒。
  - SourceForge、AlternativeTo、SaaSHub、F6S 用专用存档解析。
  - IT桔子用独立会话、浏览器方式；媒体站只收带外部链接的条目。

## 四、只收产品
所有方式抓到的条目统一经过过滤：去掉导航词（Subscribe、About Us…）、纯数字、英文超过 8 个词或中文长句等文章标题式条目、新闻关键词（融资 / 发布会 / 报道…），之后才交给 dedup 去重入库。

### Product Hunt
- 浏览器模式在 box（机房 IP）打开首页和当日 All 榜，都出现 Cloudflare Turnstile「Performing security verification / Verify you are human」交互验证。按要求不绕过、不破解。
- 正式抓取（非单源测试）会弹出可见窗口，让你自己点一下验证；通过后 Cookie 保存在内置浏览器会话里，后续抓取可以复用。
- 公开存档：Wayback 有 2026-10-29 的首页快照，解析规则验证能拿到 44 个产品（Empacer、Scape、Notch Metrics…，含名称、简介、票数）。但 box 被 Wayback 限流（429 / 500）后，程序内这一步也取不到。

## 六、你需要做的事
1. 保持 Clash 的「系统代理」开着（默认跟随系统）；或者在 设置 → 网络与代理 里手动填 `http://127.0.0.1:7897`，再点「测试连通」。
2. Product Hunt、G2、Capterra、SourceForge 这类网站：抓取时弹出窗口就手动点一下验证；也可以先点「内置浏览器」打开网站通过一次验证。
3. IT桔子：在内置浏览器里登录一次（412 是要求登录或验证）。
4. 失效的入口：tools.so、fwol.cn（域名无法访问），WebCatalog、Insidr（404），极客公园、Gartner（403）。可以在来源设置里改入口 URL，或者直接停用。
5. 来源列表 →「只重试失败的源」，按失败原因筛选后批量处理。
