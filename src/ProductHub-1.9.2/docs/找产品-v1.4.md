# v1.4 找产品：功能说明、限制与搜索评测

## A 自然语言搜索
- 输入一句话，系统解析出意图词、约束和“类似 X”。
  - 有 AI Key：由大模型解析（8 秒超时，失败回落到本地规则）。
  - 无 Key：用本地规则解析（中文最长匹配分词、去口语词、约 90 组中英同义词）。
- 结果按相关度排序。每行给出「为什么匹配」并高亮命中词；「理解为」条显示解析结果。
- 限制：词典之外的中文说法（如「电子签名」）在离线模式下无法匹配英文产品。

## B 联网搜索
- 本地严格命中少于 3 条时，自动并发查询 Bing、DuckDuckGo HTML、GitHub、HN Show HN。
- 每个来源独立超时、独立失败；结果过滤百科、问答、榜单文章，按域名去重，标记已在库。
- 入库使用统一 GUID（幂等），入库后自动补齐官网信息。
- 限制：
  - DuckDuckGo 会间歇性出现反爬验证（显示为“被反爬验证拦截”）；
  - 未登录时 GitHub 每分钟限 10 次；
  - Product Hunt 为 JS 渲染页面，未接入；
  - Bing 对中文短语的结果质量一般。

## C 对比
- 支持 2–5 个产品、23 项左右属性，差异行高亮，可切换只看差异；AI 评分最高者带标记。
- 可导出 xlsx / md。
- 限制：未补齐的产品很多格为空，可在对比页一键「补齐缺失信息」。

## D 官网补齐
- 提取来源：meta、OG、JSON-LD、hreflang、自动发现的定价页；有 AI Key 时用大模型补充。
- 后台队列（并发 3），状态栏显示进度，详情页显示新鲜度。
- 预置数据：尝试 700 个，成功 623 个（89%）。
- 失败原因主要为 403、429 和网络错误。
- 限制：
  - 资讯类条目会提取出媒体公司的信息；
  - JS 渲染的定价表拿不到；
  - 版权行推断出的公司名偶尔错误（如 “Screen”）。
