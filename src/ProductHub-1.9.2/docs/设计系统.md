# 统一产品库 · 设计系统（v1.2）

基于 **shadcn/ui（Tailwind CSS + Radix UI）**，zinc 中性色，一个品牌强调色（靛蓝）。目标是像 Linear / Raycast 一样**安静、紧凑、键盘友好**。

- 令牌源文件：`src/ui/styles.css`（CSS 变量）、`tailwind.config.cjs`（映射）、`src/ui/lib/tokens.ts`（清单，供组件库页面和测试使用）
- 组件源文件：`src/ui/components/ui/*`（shadcn 组件）、`src/ui/components/*`（业务组合组件）
- 在应用中查看：开发模式（`npm run dev`）侧栏「组件库」，或任意地址加 `?dev=1`
- 强制检查：`tests/unit/design-system.test.ts`（每次 `npm test` 运行）

## 1. 颜色

所有颜色都是 HSL 变量，浅色在 `:root`，深色在 `.dark`，两套必须**同名、同数量**（测试校验）。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `background` / `foreground` | 白 / zinc-950 | zinc-950 / zinc-100 | 页面底色、正文 |
| `card` · `popover` | 白 | 略亮于背景 | 卡片、浮层 |
| `muted` / `muted-foreground` | zinc-100 / zinc-500 | zinc-800 / zinc-400 | 次要背景、说明文字 |
| `accent` | zinc-100 | zinc-800 | 悬停、选中背景 |
| `border` / `input` / `ring` | zinc-200 / zinc-200 / zinc-400 | zinc-800 | 分割线、输入框、焦点环 |
| `primary` | zinc-900 | zinc-100 | 默认主按钮（中性） |
| `brand` / `brand-soft` | 靛蓝 #4f5bea / 浅靛蓝 | 提亮靛蓝 / 深靛蓝 | **唯一强调色**：主操作、选中行、分类徽标、AI |
| `success` / `warning` / `destructive` | 绿 / 琥珀 / 红 | 同色相提亮 | 状态：正常 / 无数据、关注星标 / 失败、删除 |
| `sidebar-*` | zinc-50 系 | zinc-900 系 | 侧栏、标题栏、状态栏 |

规则：
- 业务代码**禁止**写死十六进制颜色和 `bg-[#…]`（测试校验）；透明度用 `/10`、`/15`、`/60` 等。
- 一屏最多一个 brand 色实心按钮；状态色只表达状态，不作装饰。

## 2. 字体与字号

字体栈：`Inter, "PingFang SC", "Microsoft YaHei UI", "Noto Sans SC", system-ui`；数字使用 `tabular-nums`；等宽字体只用于 GUID、JSON、快捷键。

| 类名 | 字号 / 行高 | 用途 |
|---|---|---|
| `text-2xs` | 11 / 16 | 计数徽标、快捷键、状态栏 |
| `text-xs` | 11.5 / 16 | 说明文字、表单标签、次要信息 |
| `text-sm` = `text-base` | **13 / 20（基准）** | 正文、表格、按钮、输入框 |
| `text-md` | 14 / 22 | 详情页一句话简介 |
| `text-lg` | 15 / 24 | 页面标题、详情产品名 |
| `text-xl` | 18 / 26 | 弹窗大标题（引导） |
| `text-2xl` | 22 / 28 | KPI 数字 |

字重只用 400 / 500（`font-medium`，强调）/ 600（`font-semibold`，标题、KPI）。**禁止 `text-[Npx]`**（测试校验）。

## 3. 间距

4px 网格：`1`=4、`1.5`=6、`2`=8、`3`=12、`4`=16、`5`=20、`6`=24。
- 控件内边距：按钮 `px-3`（sm `px-2.5`），输入框 `px-2.5`。
- 卡片 `p-4`，卡片间距 `gap-3`；页面内容区 `p-5`；工具栏 `px-3 py-2`。
- 表格行高 **36px**（虚拟列表固定），表头 32px；侧栏菜单项 28px。

## 4. 圆角 · 阴影 · 动效

| 类别 | 令牌 | 用途 |
|---|---|---|
| 圆角 | `rounded-sm` 4px | 徽标、小图标按钮 |
| | `rounded-md` 6px | 按钮、输入框、菜单项 |
| | `rounded-lg` 8px（`--radius`） | 卡片、弹窗、Sheet |
| | `rounded-full` | 状态点、进度条 |
| 阴影 | `shadow-sm` | 按钮、输入框 |
| | `shadow-md` | 下拉菜单、Tooltip、命令面板 |
| | `shadow-lg` | 弹窗、Sheet |
| 动效 | `duration-150`（fast） | 悬停、颜色变化 |
| | `duration-200`（base） | 面板滑入、弹窗淡入、详情出现 |

动效只用 `ease-out` 系；**禁止 150 / 200ms 以外的时长**（测试校验）。

## 5. 组件使用规则

| 组件 | 何时用 | 规则 |
|---|---|---|
| **Button** | 所有可点击操作 | `brand`：每个区域最多 1 个主操作（添加产品、开始使用）；`default`：查询、同步等次主操作；`outline`：次要；`ghost`：工具栏、图标按钮；`destructive`：删除，必须二次确认。图标按钮必须带 Tooltip |
| **Input / Select / MultiSelect** | 表单查询、设置 | 高度 32px；占位符写“不限 / 全部分类”这类默认语义；Select 的空值表示“不限” |
| **Table / 虚拟表格** | 数据列表 | 表头吸顶；数字列右对齐 + `tabular-nums`；行内操作悬停时才完全显现（`opacity-60 → 100`）；更多操作放右键菜单 |
| **Badge** | 分类、标签、状态 | 分类用 `brand`，标签用 `outline`，状态用 `success / warning / destructive` |
| **Tabs** | 同一对象的不同侧面（详情：概览 / 版本 / AI；来源与规则） | 页面级导航用侧栏，不用 Tabs |
| **Sheet** | AI 助手 | 非模态，可拖宽；打开时在窄屏临时收起侧栏，关闭后恢复 |
| **Dialog** | 添加 / 编辑、引导、日志 | Esc 关闭；第一个输入框自动聚焦；底部操作栏右对齐 |
| **DropdownMenu / ContextMenu** | 导出格式、列设置、行操作 | 菜单项带图标；危险项放最后并用分隔线隔开 |
| **Command** | `Ctrl/⌘+K` | 分组：产品 / 找竞品 / 跳转 / 操作；每个跳转项显示快捷键 |
| **Tooltip** | 图标按钮、截断文字 | 延迟 300ms；内容包含快捷键 |
| **Skeleton** | 所有异步区域 | 形状与真实内容一致（行、卡片、KPI） |
| **EmptyState** | 列表 / 卡片无数据 | 图标 + 标题 + 一句说明 + 可选操作（如「重置条件」） |
| **Toast** | 操作结果 | 底部居中，3.5 秒；成功为默认样式，失败为 `err`；长任务结束必须给出数量结果 |

## 6. 状态规范

| 状态 | 表现 |
|---|---|
| 悬停 | `hover:bg-accent`（列表 `bg-muted/50`），150ms |
| 选中 | 列表行 `bg-brand-soft`；侧栏 `bg-sidebar-accent` + `font-medium` |
| 焦点 | `focus-visible:ring-2 ring-ring`（+ `ring-offset-1`），对比度 ≥ 3:1；全局 `:focus-visible` 兜底 outline（键盘可见，鼠标点击不显示） |
| 按下 | 按钮 `active:scale-[.97]`，行内图标 `active:scale-90` |
| 勾选 | 行 `data-[checked]:bg-brand-soft/60`；当前行 `bg-brand-soft` + 左侧 2px 品牌色内描边 |
| 禁用 | `opacity-50` + `pointer-events-none` |
| 加载 | 区域用 Skeleton；按钮内用旋转图标并改文案（“同步中…”） |
| 空 | EmptyState |
| 错误 | 字段：`aria-invalid` → `border-destructive` + 下方 `text-xs text-destructive`（`role=alert`，`aria-describedby` 关联）；区域：`ErrorState`（圆形图标 + 原因 + 重试）；全局：Toast（err）；持续性错误（来源失败）进入状态栏 / 首页 |
| 只读 | 标题栏「内部预览 · 只读」徽标，隐藏所有写操作入口 |

### 6.1 反馈与撤销（v1.3）
| 场景 | 规范 |
|---|---|
| 破坏性操作（删除） | 不弹 confirm：立即隐藏 → Toast「撤销」6 秒 → 再提交；离开页面时 `sendBeacon` 提交 |
| 可逆操作（关注、标签） | 乐观更新；失败回滚 + Toast「重试」；成功 Toast 带「撤销」 |
| 不可撤销的设置（清除 API Key） | 二次点击确认（按钮变红「再次点击确认清除」，4 秒后复原） |
| 长任务（AI 回答） | 流式呈现 + 光标；可「停止」；失败卡片 + 「重试」 |

### 6.2 对比度（v1.3）
所有颜色对由 `tests/unit/contrast.test.ts` 守护：正文 ≥ 4.5，状态色 / 焦点环 ≥ 3（亮、暗两套）。首字母头像渐变端点亮度 ≤ 32%，白字 ≥ 4.5（`tests/unit/avatar.test.ts`）。

## 7. 布局

标题栏 40px（可拖拽）→ 侧栏 248px（图标栏 52px）+ 主区（最小 420px）+ 详情分栏（340–760px，可拖拽，宽度记忆）+ AI Sheet（可拖宽）→ 状态栏 24px。

## 8. 写作规范（术语）

见 `docs/使用手册.md` 附录 A。原则：同一概念只用一个词；按钮用动词开头（“导出报告”“立即同步”）；数字和单位之间加空格（“48 个来源”）；中英文之间加空格。
