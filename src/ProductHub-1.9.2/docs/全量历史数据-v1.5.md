# v1.5 全量历史数据（离线）

## 数据规模（截至 2026-10-13）
- 产品 106,085 个（v1.4 为 2,865 个）；发布记录（版本历史）146,652 条。
- 本地图片 29,182 张，缩放到 ≤128px webp，打包时再缩到 ≤96px。
- 官网信息补齐 1,469 个。
- 来源：成功 176 个，失败 39 个，跳过 26 个媒体来源。逐来源明细见 `crawl-report-v1.5.md` / `.csv`。

## 抓取方法
`npx tsx scripts/crawl-history.ts [--only=seq,..] [--redo=1] [--minutes=45] [--conc=16] [--phase=crawl|images|all]`

断点续跑：每个来源每种策略的进度记在 `crawl_state` 表里，数据库每 60 秒存盘一次。中断后用同一条命令即可从游标继续。

| 来源 | 策略 | 范围/上限 |
|---|---|---|
| HN Show HN | Algolia API，按 created_at_i 时间窗口翻页 | points≥20，覆盖 2009 年至今 |
| GitHub | Search API，按半年 created 窗口，每窗口 10 页 | stars≥3000，2008 年至今 |
| BetaList | 首页 `?page=N` 存档 | 已到第 ~375 页（2017-12），未抓完 |
| Product Hunt | RSS（排行榜和 GraphQL 需要登录，Cloudflare 403） | 最近 50 条 |
| 其他 | 规则列表分页 + sitemap 产品详情页 | 每来源 ≤4000 条，sitemap 详情 ≤2500 页，单来源 45 分钟时间盒 |
| 失败来源 | 备用 URL → 真实 UA → Playwright 系统 Chrome 渲染（等待 Cloudflare 验证） | — |

- 礼貌抓取：每个主机串行，至少间隔 1 秒；遇到 429/503 时按 Retry-After 或指数退避（15 秒起，最长 10 分钟）。
- 噪音：26 个新闻/媒体来源不做历史回溯；只出现在这些来源的 319 个文章条目已删除；新条目按标题/URL 规则过滤（约 1,100 条被过滤）。

## 已知限制
- 「最早日期」来自 launch_date。sitemap 来源取的是 lastmod，代表收录或更新日期，不一定是发布日期。
- 约 50 个来源的 sitemap 在时间盒内没抓完（状态 partial），可以用同一命令继续。
- 已安装旧版本的用户不会自动合并新数据：内置数据只在首次启动、数据库不存在时导入。可以用数据包替换数据库（见交付目录说明）。
